#TRADEZONE DATA EXPLORATION

PROJECT OVERVIEW:
This project focuses on cleaning & analyzing Tradezone dataset to improve data quality and extract useful insights from the available records.

PROBLEM: 
1. Raw datasets contain few inconsistent entries.
2. Some sellers are dragging down overall platform ratings
3. Customer retention is dropping
4. Certain products categories are underperforming despite heavey promotion spend

TASK: 
1. Combined data review
2. Understanding what is actually happening in the business
3. What to do about it

WHAT I DID:
1. Clean the data
2. Answer specific business questions using SQL 
3. Deliver a concise analyst memo that turns query results into decisions the leadership team can act on

TOOLS: MySQL, Cloud tools

PROJECT RESULT:
1. Customer Acquisition and 30-day conversion
2. Product performance
3. Seller fulfillment efficiency
4. Quarterly Revenue trends
5. Customer spend segmentation
6. Payment method preferences by statement
7. Review Ratings and Sales performance
8. Top seller bonus qualification

KEY FEATURES:
1. Dataset exploration and profiling.
2. Missing-value and duplicate assessment.
3. Data type and format standardization.
4. Exploratory data analysis.
5. Identification of patterns and trends.
6. Summary of findings and visual reporting, where applicable.
